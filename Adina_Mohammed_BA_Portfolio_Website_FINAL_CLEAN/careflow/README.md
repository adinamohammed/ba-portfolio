# CareFlow — Smart OPD & Digital Patient Records System

Prepared by: Adina Mohammed

## How to view

1. Open `index.html` to view the main BA portfolio case study.
2. Click `Open Live OPD Prototype` to open `careflow-opd-workflow-prototype.html`.
3. Keep the `artefacts/` folder in the same location so downloadable artefact links work.

## Included files

- `index.html` — main CareFlow case study page
- `careflow-opd-workflow-prototype.html` — clickable OPD workflow prototype
- `artefacts/CareFlow_Data_Dictionary.xlsx`
- `artefacts/CareFlow_UAT_Summary.xlsx`
- `artefacts/CareFlow_RTM_Sample.xlsx`
- `artefacts/CareFlow_SQL_Reporting_Notes.pdf`
- `artefacts/CareFlow_SQL_Reporting_Notes.docx`

## Portfolio boundary

This is a self-initiated Business Analyst portfolio case study using fictional data for learning and demonstration purposes. It is not a live client project, production HMIS/EMR, real hospital implementation, or clinical decision-support tool.

The live prototype is a front-end communication artefact only. It does not connect to real patient data, ABHA/PHR APIs, payment gateways, WhatsApp/SMS APIs, lab machines, pharmacy inventory systems, or a real database.
